# API reference

This page covers the numeric core. The plotting interface lives in package
extensions and is documented on the [Makie](@ref) and [Plots](@ref) pages: a
specification goes last in a plotting call, after the values it colors, and
`Colorbar(position, spec)` builds Makie's colorbar from one.
